# Privacy & Safety Rules

Applies to all code handling user/student data.

- Data minimization by default.
- Treat student profiles as high-sensitivity personal data.
- Do not collect health, disability, family-income, exact location, or other sensitive attributes in MVP.
- Do not use student data for advertising targeting.
- Provide user deletion and export paths.
- Separate authentication identity from academic profile data where practical.
- Use least-privilege database policies.
- Use row-level security.
- Never expose service-role keys to the browser.
- Audit admin edits to program requirements.
- Requirements must retain source provenance.
- Do not use an LLM as the authority for program eligibility.
- If AI explanation conflicts with structured evaluation, structured evaluation wins.
- Avoid manipulative engagement or "dependency" design for minors.
